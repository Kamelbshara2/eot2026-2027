## LO19 Other trigonometric functions (rebuilt)
| Problem (as reported) | Cause | Fix |
|---|---|---|
| Questions were predictable | Three choices had the same asymptote text and differed only in the period; the fourth said "no vertical asymptotes", which is never true for csc, sec or cot. The correct picture file always ended in `-0`. | Each choice is now a complete, true description of its own graph, made from one named mistake: wrong period formula, wrong family (sec/csc or tan asymptotes), or a missed reflection. In alternate questions one choice combines two mistakes, so the correct choice is not simply the "middle" one. Files are named by choice letter. |
| Asymptote locations were wrong | In every period distractor, the text listed asymptotes that did not match that choice's own graph (e.g. a graph with asymptotes every 2π/3 labelled x = 4nπ/3). | Text and graph are generated from the same function and checked numerically (period, asymptotes, extremum or intercepts, increasing/decreasing). |
| x-axis numbers vs π | Graphs used a numeric axis (−8 … 8), so 4π/3 ≈ 4.19 could not be read. | **Decision: π.** Ticks are every half asymptote spacing, labelled in π (−8π/3, −2π, …, 8π/3). Asymptotes are dashed red lines. All four choices share one window and the same ticks. |
| Formatting | `y = 1 csc(3/4 x)`, `x = nπ/(3/4)`, `y = 1(−1)ⁿ` | `y = csc(3x/4)`, `x = 4nπ/3`, properties one per line (fits a phone screen). |
